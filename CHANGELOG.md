# Changelog

## 1.1.0 - 2026-10-23

- Add Vintage Lab with v86 to boot user-selected, bootable 16/32-bit x86 ISO images in the browser.
- Keep OS images local to the browser; include only emulator firmware and no operating-system images.
- Add an optional temporary 512 MB virtual disk for installers.

## 1.0.0 - 2026-10-23

First stable release of the VetTV Retro Desktop browser shell.

- Vet2000 desktop with Start menu, taskbar, draggable/resizable windows, and session restore.
- IndexedDB virtual filesystem with Files, Notepad, Image Viewer, and Calculator.
- Original VetTV chrome and clear non-affiliation messaging; executable files are not run.
- GitHub Pages workflow audits dependencies, checks Svelte/TypeScript, and builds the production site before deployment.

Vet98/VetXP themes, remote iframe apps, games, and local profiles are deferred to future releases.
